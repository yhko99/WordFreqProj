## 슬라이드 1 — 서비스 소개 (20초)

"화장품 리뷰 감성분석 서비스"를 만들었습니다.
무신사·올리브영·쿠팡 3개 쇼핑몰 화장품 리뷰를 크롤링해서, 리뷰 텍스트만 보고 긍정인지 부정인지 자동으로 판단하는 모델을 학습했고, 이걸 Streamlit으로 웹 서비스까지 만들었습니다.

→ 머신러닝/딥러닝으로 해결한 부분: 사람이 리뷰를 일일이 읽고 분류하지 않아도, 문장만 넣으면 신경망이 바로 긍정/부정을 판단합니다.

## 슬라이드 2 — 데이터 수집 (40초)

무신사는 직접 크롤링했고, 올리브영·쿠팡은 같은 조 팀원들이 크롤링한 데이터를 받아서 합쳤습니다. 합쳐서 50만 건이 넘습니다.

크롤링하면서 두 가지 문제가 있었습니다.
1. 무신사가 React로 만들어진 사이트라 처음 잡은 HTML 선택자가 다 틀려서 상품이 하나도 안 잡혔습니다. 개발자도구로 직접 구조를 봐서 실제 속성을 찾아 해결했습니다.
2. 리뷰를 더 가져오려고 "이전 후기 보기"를 눌렀는데 같은 페이지를 계속 반복해서 크롤링하는 문제가 있었습니다. 알고 보니 무신사는 스크롤할 때마다 리뷰가 추가로 로드되는 방식이라, 페이지 이동 대신 스크롤을 자동으로 시키는 방식으로 바꿔서 해결했습니다.

## 슬라이드 3 — 라벨링 문제와 해결 (★ 가장 중요, 75초)

모델을 학습시키려면 "이 리뷰는 긍정, 이 리뷰는 부정"이라는 정답이 있어야 합니다. 그런데 무신사는 구매 만족도가 높은 사람만 평점을 남기는 구조라서, 평점 기준으로 분류하면 부정 리뷰가 0.4%밖에 안 됐습니다.

처음에는 평점 대신 리뷰 텍스트에 있는 단어(자극, 트러블, 별로 같은 단어)로 직접 분류해봤습니다. 부정 비율을 21.9%까지는 끌어올렸는데, 문제는 "자극이 전혀 없어요"처럼 분명히 긍정인 문장도 "자극"이라는 단어 때문에 부정으로 잘못 분류되는 경우가 많았습니다.

그래서 팀원들이 크롤링한 올리브영·쿠팡 데이터를 확인했더니, 이 두 곳은 실제 평점 기준으로도 부정 비율이 8~17%로 충분히 높았습니다. 그래서 3개 플랫폼 데이터를 합치고, 키워드 추측이 아니라 실제 평점(1~2점은 부정, 4~5점은 긍정)으로 다시 라벨을 매겼습니다. 다만 무신사 데이터가 워낙 많아서 그대로 합치면 부정 비율이 다시 낮아지기 때문에, 긍정 리뷰를 일부만 뽑아 쓰는 방식으로 부정 25%, 긍정 75% 비율을 맞췄습니다. 최종 학습 데이터는 16만 7,996건입니다.

## 슬라이드 4 — AI 모델 구현 (45초)

전처리는 4단계로 진행했습니다. 결측치 제거, 한글과 공백만 남기는 정제, 중복 리뷰 제거, 그리고 형태소 분석입니다. 한국어는 띄어쓰기만으로 단어를 구분할 수 없어서 형태소 분석이 꼭 필요한데, 16만 건이 넘다 보니 이 단계에만 5분 정도 걸렸습니다.

모델 구조는 Embedding으로 단어를 벡터로 바꾸고, LSTM(64)을 지나서 Dense(16) Dense(2)로 긍정/부정을 분류합니다. 리뷰는 문장이라서 단어 순서와 맥락이 중요한데, 이걸 잘 보는 게 순환신경망이라서 LSTM을 기본 모델로 썼습니다. 이 LSTM 모델의 테스트 정확도는 94.2%입니다.

---

## 슬라이드 5 — 모델 비교: LSTM vs GRU vs Transformer (45초)

여기서 같은 데이터로 LSTM 말고 GRU, Transformer도 같이 학습해서 비교해봤습니다.

GRU가 정확도 94.3%, 부정 F1 88.5%로 셋 중 가장 좋았고, 학습도 7번만 반복해서 가장 빨리 끝났습니다. Transformer는 학습 속도 자체는 가장 빨랐지만(118초), 정확도는 셋 중 가장 낮았습니다. 리뷰 문장이 최대 100단어 정도로 짧다 보니, 긴 문맥을 잘 보는 Transformer의 장점이 충분히 드러나지 않은 것 같습니다. 결과적으로 이번처럼 짧은 텍스트 분류에는 GRU가 가장 효율적이었습니다.

## 슬라이드 6 — 배포 및 시연 (10초 소개 + 45초 영상)

Streamlit으로 4가지 기능을 만들었습니다. 전체 통계, 상품별 리뷰 탐색, 실시간 감성 예측, 그리고 LSTM·GRU·Transformer 중 골라서 쓸 수 있는 모델 선택 기능입니다. 직접 돌아가는 모습을 영상으로 보여드리겠습니다.
