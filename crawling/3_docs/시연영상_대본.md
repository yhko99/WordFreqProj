# 시연 영상 대본 (목표 45초)

## 녹화 준비

1. 먼저 Streamlit 앱 켜두기
   ```
   conda activate aiservice26
   cd E:\_AIService26\Webcrolling\crawling
   streamlit run app.py
   ```
2. 브라우저 창을 적당히 키워서 글자가 잘 보이게 (전체화면 추천)
3. 화면 녹화는 **윈도우 기본 기능**으로 충분합니다 — `Win + G` 눌러서 Xbox Game Bar 열고 녹화 버튼(●) 클릭. 따로 프로그램 설치 안 해도 됩니다.
4. 마이크로 직접 말하면서 녹화하거나, 녹화 후 나중에 더빙해도 됩니다.
5. 미리 입력할 문장 2개를 메모장에 복사해두면 타이핑 시간을 줄일 수 있습니다:
   - `촉촉하고 발림성도 좋아서 재구매 했어요`
   - `피부에 트러블이 생겨서 너무 실망이에요`

---

## 샷 리스트 (말하면서 클릭)

| 시간 | 화면 동작 | 말할 내용 |
|---|---|---|
| 0:00–0:08 | "상품별 리뷰" 페이지 클릭 → 상품 하나 선택 | "이 페이지에서는 상품을 고르면 그 상품의 리뷰 목록이랑 긍정·부정 비율을 바로 볼 수 있습니다." |
| 0:08–0:20 | "실시간 감성 예측" 페이지로 이동 → 첫 문장 입력 → 분석하기 클릭 → 결과(긍정) 확인 | "이번엔 직접 문장을 넣어볼게요. '촉촉하고 발림성도 좋아서 재구매 했어요' — 긍정으로 정확히 판단합니다." |
| 0:20–0:30 | 입력창 지우고 두 번째 문장 입력 → 분석하기 클릭 → 결과(부정) 확인 | "반대로 '피부에 트러블이 생겨서 너무 실망이에요'는 부정으로 잘 잡아냅니다." |
| 0:30–0:45 | 왼쪽 사이드바에서 모델 선택을 GRU로 변경 → 정확도/지표 카드 바뀌는 것 보여주기 | "왼쪽에서 모델을 GRU나 Transformer로 바꾸면, 그 모델의 정확도랑 지표가 바로 바뀌어서 비교해볼 수 있습니다." |

## 촬영 팁

- 한 번에 안 되면 여러 번 끊어 찍어서 나중에 이어붙여도 됩니다 (Win+G로 끊어서 여러 클립 녹화 후, PowerPoint나 곰믹스 등으로 이어붙이기)
- 클릭하고 결과 뜰 때까지 1~2초 정도 정지해서 화면이 바뀌는 걸 시청자가 볼 수 있게 하기
- 마우스 커서를 천천히 움직이기 — 너무 빠르면 뭘 클릭했는지 안 보임
- 발표 시간 5분 안에 들어가야 하므로, 영상은 **45초를 넘기지 않기** (길어지면 슬라이드 5에서 시간을 줄이기)

## 영상을 못 찍을 경우 대안

녹화가 어려우면 발표 당일 **직접 화면 공유로 라이브 시연**해도 됩니다. 이 대본 그대로 따라 하면 됩니다 — 클릭 순서와 말할 내용이 동일합니다.
